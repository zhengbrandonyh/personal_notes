# V21 草稿：捕获、今日行动、排期和保存

本版本仅保存草稿，生产 V20 与 V9 固定基准均保留。没有迁移用户浏览器数据，也未创建用户真实数据基准备份。

- 今天和事项列表支持只填标题回车保存；抽屉标题支持回车。中文输入法组合输入不触发提交，失败保留输入。
- plannedFor 独立记录“加入今天”，不改截止日期和优先级。逾期列表保留，今日安排仍展示有时间的日程。
- 月历拖动改期及右端日期拉伸；周历新增时间网格，支持触摸/鼠标拖动、15 分钟时长拉伸，原时长和节点偏移保留。跨天事项仍在顶部柱状区，精确时分可在抽屉修改。
- 所有排期保存及 AI 执行前检查其他分类的占用、预计用时、工作日及时段约束。用户可取消或明确保留冲突；事务内再次检查数据是否变化。节点超出区间直接阻止保存。
- 排期和截止日期独立编辑，移动日程不会改截止日期。
- 笔记每次输入写本地恢复草稿，停笔 900ms 自动提交。提交基于原始版本比较，冲突/失败暂停自动保存。保存中继续输入不丢失。不同页面的恢复草稿分开保存；旧于最新记录的冲突草稿仍可恢复，不自动覆盖。
- AI 范围可选择当前分类或仅聊天；每项操作展示原因；支持节点、预计分钟数、排期约束和加入今天。执行前保留字段白名单、记录版本和范围验证。模型真实请求仍需站点所有者登录。
- 每天/工作日/每周/每月重复，在完成时生成一个后续事项，保留历史。月末按原始日号处理（1/31 → 2/28 → 3/31）。重新打开旧记录再完成不会重复生成后续事项。
- 网页打开时每 15 秒检查提醒，通过 Web Locks 与送达日志去重。已授权时尝试系统通知，同时提供网页内提醒；系统通知失败回退网页内。顶部可测试授权和查看送达记录。系统“已发出”不等于操作系统一定展示。

## 验证

类型检查及 65 项自动测试通过。隔离浏览器测试通过标题回车、失败保留、900ms 自动保存、刷新恢复、多页面冲突、实际拖动改期和实际拉伸时长。

HTTP 内部预览不支持生产要求的 Web Locks，正式存储写入未在预览中放宽；浏览器成功保存/恢复测试使用隔离夹具和真实组件，未操作用户真实数据。AI 后端真实模型响应、生产系统通知权限与真实设备后台行为未在草稿环境做端到端验收。

## 边界

提醒只在网页打开时工作，关闭浏览器后的后台推送需要后续服务端推送能力。常见重复规则是完成后生成下一次，不包含法定节假日、自定义间隔或结束日期。周期按原计划推进；完成逾期事项时跳过已过去的周期。未新增云同步或登录迁移。
