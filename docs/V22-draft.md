# V22 草稿：密集日历和加入今天位置

本版本保存为草稿，生产仍为已发布的 V21。保持 V9 固定基准、当前用户浏览器记录和运行环境配置。

- 四象限事项卡片的“加入今天 / 移出今天”移至标题同行的右侧，取消原来的底部独立一行。按钮固定宽度行为并保留长标题的可用空间。
- 月历、周历的跨天柱状按内容分配行高。带关键节点的柱状保留标题与节点两行，无节点的柱状保持紧凑。
- 每个节点标签限制在对应日期格内；同一天多个节点合并展示，长名称截断，完整内容仍可在事项中查看。
- 修正单日事项标题与拉伸按钮争夺空间时的标题溢出。

验证：类型检查、67 项自动测试通过。浏览器使用隔离的 12 条密集跨天示例与同日多节点，验证标题和节点无重叠、标签无越界、窄容器无柱状溢出。实际点击“加入今天”会切换为“移出今天”，两种状态均在卡片右侧。未接触用户真实记录。
