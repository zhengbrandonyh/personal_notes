# 昼夜簿 v2

React / Vite 静态应用，沿用原网站和本地记录。当前版本修复交互评审中的数据覆盖、笔记定位、时间、导入和主流程问题。

## 开发与发布

- Node.js 24、pnpm 11.25.0。
- pnpm dev / pnpm build / pnpm test；TypeScript 检查：pnpm exec tsc --noEmit。
- build 生成 dist 及同版本 daynight-offline.html；不发布旧原型 HTML 或设计交付 ZIP。
- .openai/hosting.json 保留原项目 ID 和公开访问权限。

## 数据与兼容

- 使用同源 Web Locks 串行事务和单个 localStorage v2 快照，跨标签页同步；读取旧版数据，首次成功写入时迁移，保留旧键作为原始恢复材料。
- 同条记录编辑时校验原始版本，冲突保留草稿；存储失败不会显示成功。
- 需要 HTTPS 或本地文件可信上下文以及 Web Locks 支持；不支持时停止写入并提示导出草稿，不使用不安全的静默覆盖降级。
- 备份导入完整校验、预览、确认替换；替换前自动保存一份可恢复快照。无跨设备同步。
- 笔记与事项均显式保存；有草稿时离开会提示。笔记草稿可导出 Markdown，事项草稿可导出 JSON。

## 产品口径

- 截止日期与计划时段独立；各页面按截止日期判断逾期，不把计划结束自动改成截止日期。
- 日期显示和每日完成统计统一使用浏览器本地时区。
- 助手是本地规则排期，无模型和前端 API Key；优先重要/紧急事项、默认每项 1 小时，避开冲突和已过时间，确认后再次校验。
- 周摘要按真实完成记录生成，可保存为复盘笔记；没有 PWA 安装和云同步承诺。

## 验证

24 个现有与新增测试：非法导入无写入、替换前备份、读取最新快照、存储失败传播、排期冲突与跨天裁切等。HTTP 预览无法提供 Web Locks 安全上下文，写入流程在 HTTPS 发布后通过浏览器验收。
